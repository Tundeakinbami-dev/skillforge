# SkillForge

SkillForge is a full-stack freelance marketplace where clients can post projects and freelancers can submit proposals, create contracts, complete work, and receive payment.

## Project Goals

- Learn modern frontend development
- Learn backend development
- Learn REST APIs
- Learn database architecture
- Learn authentication and authorization
- Learn payment integration
- Learn file storage
- Learn background jobs
- Learn testing
- Learn Docker and CI/CD
- Learn blockchain integration
- Build a production-quality application
